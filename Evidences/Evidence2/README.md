# Evidencia 2: Actividad Integral de Estructuras de Datos Lineales
Instrucciones de uso del programa
Este proyecto demuestra la aplicación de estructuras de datos lineales, como stacks, queue, linkedlists, doublylikedlist.
Muestra lo ocurrido en una fecha especifica, la IP y el evento mas frecuentado. 
Se utilizo el algoritmo Quicksort para ordenar los logs.

# Ejecución
El programa está diseñado para encontrar automáticamente los archivos de datos (`log607-1.txt` y `log607-2.txt`) siempre y cuando se mantenga la estructura de carpetas original (con una carpeta `data/`, los archivos header en `include/` y codigo fuente en `src/`).

El codigo esta listo para ejecutarse con compile run o desde la terminar .\ev.exe en windows y su equivalente en linux.

# Formato de fechas
El formato se maneja en ingles, primera letra siempre mayuscula y solo los primeros 3 caracteres. 
Dia y año unicamente numeros enteros

# Uso de IA
Durante este proyecto se utilizo la IA como herramienta de apoyo en los siguientes aspectos.

    LO QUE SI SE PERMITIO
Ayuda para solucionar errores de compilacion y de adaptacion del codigo para que todos los headers funcionen correctamente. Comprender porque eran necesario hacer ciertos cambios para facilitar la integracion de los metodos solicitados. Explicacion de las instrucciones e ideas de como resolver ciertos problemas.

    LO QUE NO SE PERMITIO
Generacion de codigo desde cero, ni que resolviera el proyecto, y tampoco que creara una clase o el menu completamente por su cuenta.
Aceptacion ciega de implementaciones, el codigo que se llego a cambiar o generar automaticamente esta revisado para ver si es eficiente o si de verdad es correcto lo que la IA propuso. Un ejemplo fue que me di cuenta que 2 de mis archivos headers eran muy complicados de implementar por su estructura, tuve que hacer cambios como quitar el propio node que tenian ellos, y cambiar algunas lineas de codigo dentro de ellos mismos. Esto le pedi a la IA que me diera la solucion y leia detenidamente la razon del porque, los cambios son minusculos y se mantuvo la estructura original del codigo.
